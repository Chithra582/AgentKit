# Agent Kit Scaffolding Skill

Enables rapid bootstrapping of AI agent projects using Lamatic AgentKit.

## Core Capabilities
- Resolves templates, bundles, and full-stack Next.js kits from registry.
- Generates boilerplate `lamatic.config.ts` configuration manifests.
- Configures workspace environment variables and secret bindings.
